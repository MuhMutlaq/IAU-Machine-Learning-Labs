# Here's what I learned from Lab1
In **Lab 1**, I embarked on a journey to understand the foundations of version control and collaboration. I started by distinguishing that (**Git**) is the tool that tracks changes in my files, while (**GitHub**) is the cloud platform where I host my repositories to share and manage them. I learned that a **`repository`** acts as a **central project folder** <ins>containing all my files and their complete revision history</ins>.

I practiced the **`"GitHub Flow"`** to manage my work effectively. I learned to create a **`"branch"`**, which gave me a safe space to make edits without affecting the main project code. I saved my progress through **`"commits"`**, which serve as <ins>snapshots of my changes</ins> accompanied by descriptive messages. To finalize my work, I used **`"pull requests"`** to propose my changes and merged them back into the main branch.

Shifting to my local machine, I installed tools like **`Visual Studio Code`** and **`GitHub Desktop`**, allowing me to **`"clone"`** repositories from the internet to my computer for <ins>offline work</ins>. I also established a workflow for creating Jupyter Notebooks to combine code and text in a single document.

#### Previous Knowledge of Creating README.md File
Finally, I learned about the flexibility of documentation, specifically that I can write (**README.md**) files in <ins>many formats</ins>, utilizing either the **`original Markdown structure`** or **`HTML structure`** to present my project details.
